## Deploy commands
From /workspace/eddys-hell-app (syncs root → dist, then deploys):

  scripts/deploy-hosting.sh beta      # beta only — preferred for experiments
  scripts/deploy-hosting.sh stable    # friends site — use only for known-good
  scripts/deploy-hosting.sh both

Equivalent firebase CLI:
  firebase deploy --only hosting:beta   --project eddy-s-hell
  firebase deploy --only hosting:stable --project eddy-s-hell

GitHub Pages mirror (does not touch Firebase Hosting):
  scripts/publish-pages.sh

Do NOT move/retag v1.0.0. Tag stays on the known-good freeze.
